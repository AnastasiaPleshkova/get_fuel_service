
# GetFuel service

Приложение для получения/сохранения записей в БД для отслеживания потребляемого топлива машины
Использованы технологии:
Интеграция по REST и GRPC (авторизация по keycloak), kafka продюсер/консюмер, миграции liquibase

Проект написан на `Java 17` с использованием `Spring Boot 3.5.3`.

Для работы требуется БД `PostgreSQL`, `Kafka`.
